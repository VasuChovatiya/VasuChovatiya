## 🏆 Highlights

- 📉 **10.8 GB → 3.5 MB:** moved a client app's 108 bundled audio demos to Apple On-Demand Resources. The download became about 3,000× smaller.
- 🚀 **Faster launch, no critical crashes:** reduced launch time in Scratch Adventure and fixed critical crashes in Scratch Adventure, Wakeuply, Photo Purge and Ovulio.
- 🌍 **28–36 languages per app:** large-scale localization delivered on demand instead of bundled in the install.
- 🎨 **Theming without an app update:** remote-controlled themes and feature toggles with Firebase Remote Config.
- 👥 **Team lead:** ran day-to-day iOS work, code reviews and trainee mentoring in Agile/Scrum.
